TokSaver — загрузчик TikTok с базой аккаунтов (аналог 4K Tokkit)
================================================================

ИНТЕРФЕЙС
  - Язык: English (по умолчанию), Русский, Українська, Deutsch, Français, Español —
    выбирается в сайдбаре «Язык» (перезапуск предлагается сразу). Свой язык: файл
    lang/<код>.json (см. i18n.py) — ключ это английский текст.
  - Автосинхронизация (сайдбар): выкл / раз в 1, 3, 6, 12 часов / каждый день в ЧЧ:ММ.
    Работает, пока программа открыта; пропущенный ежедневный запуск догоняется при старте.
  - После «Синхронизировать всех» в журнале и всплывашкой — итог: новые посты, скачано,
    ошибки, общий объём, время.
  - Выбор источника cookies (браузер или путь к cookies.txt) запоминается.
  - Цветной журнал: загрузки, компоненты/сеть, авторизация, итоги, подробности.
  - «Синхронизировать всех» = проверить новые посты и докачать очередь у каждого аккаунта;
    «Остановить всех» прерывает всё сразу.
  - Современный дизайн: скруглённые углы, синий акцент, тёмная и светлая темы.
  - РОВНЫЕ ТОНКИЕ ПОЛЗУНКИ: свои плоские скроллбары (сайдбар, список
    аккаунтов, журнал) — бегунок строго пропорционален видимой части,
    перетаскивается мышью, клик по желобу листает страницу, колесо мыши
    скроллит ту зону, над которой курсор.
  - ВСТАВКА ПРИ ЛЮБОЙ РАСКЛАДКЕ: Ctrl+V / Ctrl+C / Ctrl+X / Ctrl+A и
    Ctrl+Insert работают даже когда в Windows выбран русский язык
    (программа распознаёт физическую клавишу, а не букву раскладки).
    Плюс меню по правому клику в полях ввода: Вставить / Копировать /
    Вырезать / Выделить всё.
  - Ширина кнопок подбирается по фактической ширине надписи: подписи
    («Синхронизировать всех») не обрезаются даже при масштабе экрана
    125–150% в Windows.
  - ДВЕ ТЕМЫ: тёмная и светлая. Переключатель — кнопка в шапке окна
    («Светлая тема» / «Тёмная тема»), выбор запоминается
    (data/settings.json).
  - Крупные карточки в один ряд: обложка последнего скачанного видео,
    статистика (скачано / в очереди / время синхронизации / ДИАПАЗОН),
    заметка. Шрифты и кнопки укрупнены: всё читается без напряжения.
    Пока обложки нет, в кружке-рамке — ФОТО ПРОФИЛЯ: аватар скачается
    сам при первом показе карточки и кэшируется в avatar.jpg внутри
    папки аккаунта (обрезан по кругу, обводка в цветах темы). Пока
    аватар не скачался — рисованная иконка-силуэт в цветах темы.
    Если первая попытка сорвалась (обходчик ещё поднимался), программа
    повторит её сама, как только ByeDPI заработает.
  - Обложка берётся у последнего скачанного поста (официальный oembed
    TikTok) и кэшируется в cover.jpg внутри папки аккаунта — повторные
    запуски показывают её без сети.
  - Прогресс скачивания — полоска прямо на карточке («готовлю список…»,
    3/12), после завершения исчезает.
  - Всплывающие уведомления в правом нижнем углу — ровные горизонтальные
    плашки: «скачано», ошибки; живут 4 секунды, кликом снимаются; после
    исчезновения не остаётся никаких следов (ни серого пятна, ни
    перекрытых кликов); подробности всегда в журнале.
  - Журнал внизу — панель на всю ширину с явной кнопкой «Показать
    журнал» / «Скрыть журнал» (счётчик событий виден всегда).
    По умолчанию журнал раскрыт; свернутость запоминается.

КАК ЗАПУСТИТЬ
  1. Нужен Python 3.9+, рекомендуется 3.12 или 3.13 (при установке поставьте
     галочку "Add to PATH"). Самые свежие версии Python (3.14+) могут не
     дружить с библиотеками — программа предупредит об этом в run.log.
  2. Двойной клик по «Запустить.bat» (или в папке: python main.py).
     Чёрное окно консоли закрывается само сразу после открытия программы —
     окно программы живёт своей жизнью, консоль ему не нужна. Если Python
     не найден, окно останется и объяснит, что установить.
  3. ПЕРВЫЙ запуск занимает 1-2 минуты и окна пока не показывает: программа
     создаёт собственное окружение .venv рядом с собой и ставит в него
     библиотеки из requirements.txt (версии закреплены; системный Python не
     засоряется). Ход установки виден в run.log. Потом окно откроется само.
     Дальше при каждом старте программа скачивает/проверяет:
       - yt-dlp     — движок скачивания (~18 МБ), с проверкой SHA-256 по
                      официальному файлу SHA2-256SUMS релиза. Файл, не
                      прошедший проверку, не устанавливается и не запускается;
       - ByeDPI     — обход блокировок (Windows), закреплён на версии v0.17.3,
                      контрольные суммы зашиты в программу; SOCKS-прокси
                      слушает ТОЛЬКО 127.0.0.1 (порт — в настройках);
       - gallery-dl — для фото-постов (каруселей).
     Если вышел новый yt-dlp, он обновится сам (TikTok часто меняется).
     Отключить: "ytdlp_auto_update": false в data/settings.json.
     Календарик выбора даты встроен — ничего доустанавливать не нужно.
     Даже если Pillow установить не удалось, программа запустится:
     на карточках будет кружок-аватар, но обложки видео показываться
     не будут (доустановите Pillow и перезапустите).
  4. Обновить версии библиотек осознанно: поправьте номер в requirements.txt
     и удалите папку .venv — окружение соберётся заново.
     Не хотите .venv: переменная окружения TOKSAVER_NO_VENV=1.

НАСТРОЙКИ (data/settings.json)
  theme            "dark" | "light" — тема (меняется кнопкой в шапке);
  byedpi_port      порт SOCKS-прокси ByeDPI, по умолчанию 1080. Если порт
                   занят другой программой, берётся ближайший свободный;
  ytdlp_version    "latest" (по умолчанию) или тег релиза, например
                   "2026.11.01" — тогда будет установлена именно эта версия;
  ytdlp_auto_update  true/false — обновлять yt-dlp при выходе новой версии;
  parallel_downloads сколько постов качать одновременно, 1-4 (по умолчанию 1;
                   меняется и в сайдбаре «Параллельных загрузок»);
  accounts_sort, posts_sort  выбранные сортировки (запоминаются сами).
  posts_view  вид окна постов: "list" (список) или "grid" (плитки с превью);
              переключается кнопкой «Список / Плитки» над списком.
  Файл можно править блокнотом при закрытой программе.

КАЖДЫЙ АККАУНТ — ОТДЕЛЬНАЯ ПАПКА ПО ПОСТОЯННОМУ ID
  data/
    accounts.db           — список аккаунтов (маленький реестр)
    settings.json         — тема и настройки интерфейса
    0001/
        account.txt       — текущий логин, ссылка, постоянный ID, заметка
        videos.db         — посты этого аккаунта
        media/            — скачанные видео и фото этого аккаунта
        cover.jpg         — обложка карточки (последнее скачанное видео)
        avatar.jpg        — фото профиля для кружка на карточке
    0002/
        ...

  - Имя папки ПОСТОЯННОЕ (только номер): логин автора может смениться
    сколько угодно раз — папка не переименовывается, а текущий логин
    всегда виден в файле account.txt внутри. Ничего не теряется.
  - Удалить аккаунт = удалить его папку. В программе: кнопка «Удалить»
    на карточке → «Да» (удалить с папкой) или «Нет» (только из списка,
    папку оставить).
  - Можно удалить папку прямо в Проводнике — программа не сломается:
    при следующей синхронизации она создаст папку заново и перекачает аккаунт.
  - Папки независимы; папку можно переносить/копировать — самодостаточна.
  - Кнопка «Папка» на карточке открывает папку аккаунта.

АВТОРИЗАЦИЯ (ДОСТУП К ПОСТАМ)
  Без входа список постов не получить в двух случаях:
    - закрытый профиль — посты видны только подписчикам;
    - ОТКРЫТЫЙ профиль с замком «Log in to TikTok» — TikTok иногда требует
      вход даже для публичных аккаунтов («этот автор ограничил аудиторию»).
      Программа распознаёт эту страницу и пишет об этом в журнал.
  Порядок:
    1. Войдите в свой TikTok в браузере (chrome / firefox / edge / brave /
       opera / vivaldi / chromium) — там, где вы подписаны на этот аккаунт;
    2. В сайдбаре слева раздел «АВТОРИЗАЦИЯ» (сайдбар прокручивается):
       РЕКОМЕНДУЕТСЯ: нажмите «Выбрать файл cookies.txt» и подайте файл,
       экспортированный расширением вроде "Get cookies.txt LOCALLY" ТОЛЬКО
       для tiktok.com — программа получит доступ к одной сессии, а не ко
       всем вашим сайтам;
       ИЛИ (менее безопасно) выберите браузер в списке — тогда yt-dlp
       прочитает ВСЕ cookies этого браузера (почта, банки, соцсети).
       Программа перед этим просит явное подтверждение. Если выбран и файл,
       и браузер, используется файл.
    3. Нажмите «Синхронизировать» на карточке аккаунта.
  Cookies — это ключи от ваших аккаунтов. Не отправляйте cookies.txt никому
  и удаляйте файл после использования. Если вы подозреваете взлом своих
  аккаунтов, не используйте режим «из браузера».
  Если вы НЕ подписаны на закрытый аккаунт, список постов не увидит даже
  браузер — сначала подпишитесь.

ПРЕВЬЮ И СОРТИРОВКА
  Окно «Посты аккаунта» (клик по карточке): справа от списка — превью выбранного
  поста. Список остаётся быстрым текстовым (без картинок в строках): превью
  делает ОДИН фоновый поток и кладёт маленькие JPEG в кэш data/<аккаунт>/thumbs/,
  окно лишь показывает готовый файл — поэтому интерфейс не лагает. Источник
  превью — картинка поста от yt-dlp, а если её нет — кадр из видео (нужен
  ffmpeg). Кэш сохраняется между запусками; «Пересоздать превью» перестраивает
  его. «Сортировка» есть и в окне постов (новые/старые/по названию/очередь
  первой/по порядку добавления), и над списком аккаунтов (по добавлению/имени/
  последней проверке/скачанному/очереди).

ПАРАЛЛЕЛЬНЫЕ ЗАГРУЗКИ
  По умолчанию посты качаются по одному (надёжнее). В сайдбаре можно выбрать
  2-4: тогда несколько загрузок идут одновременно. Если TikTok отвечает «слишком
  много запросов» (429), все потоки делают общую паузу, которая растёт до 2 минут.
  «Пауза» и «Стоп» работают и в параллельном режиме: уже идущие загрузки
  дорабатывают, новые не стартуют.

БЕЗОПАСНОСТЬ (что делает программа)
  - Ввод проверяется: ник, ссылка (только настоящие tiktok.com), tiktokuser:ID.
    Строки вроде «--exec ...» отвергаются и до yt-dlp не доходят.
  - cookies отправляются только на tiktok.com и не пересылаются при редиректе
    на другой сайт; из cookies.txt читаются только записи tiktok.com.
  - Ответы сети ограничены по размеру и времени; файлы пишутся только в папку
    аккаунта; процессы yt-dlp/gallery-dl имеют лимит времени и закрываются
    вместе с программой.
  - Из журнала и logs/toksaver.log вырезаются значения cookies/токенов.

ДИАПАЗОН ЗАГРУЗКИ (как в 4K Tokkit)
  В сайдбаре «Сколько скачивать сразу»:
    - Все        — скачать весь аккаунт целиком (весь список постов);
    - Последние  — только N свежих постов (по умолчанию 50, потолок 500);
    - Период     — посты за даты «с … по …»: нажмите кнопку «Календарь»
                   рядом с полем — откроется календарик (стрелками ‹ ›
                   листаются месяцы); можно и вписать дату руками
                   (01.01.2024 или 2024-01-01).

  КАК ЭТО РАБОТАЕТ ПОТОМ (важно):
    1. Диапазон применяется при ПЕРВОЙ загрузке аккаунта.
    2. Диапазон — ПОСТОЯННАЯ ЗАДАЧА аккаунта: он действует при КАЖДОЙ
       синхронизации, пока вы его не измените. «Последние N» держат
       нижнюю границу (старьё не тянется), «Период» — ОБЕ границы:
       посты новее даты «по» тоже НЕ качаются, пока период не изменят.
    3. Последующие нажатия «Синхронизировать» качают ТОЛЬКО НОВИНКИ.
       Старые посты больше НЕ докачиваются «сами» — сколько бы раз вы
       ни нажимали.
    4. Посты вне диапазона помечены «вне диапазона» (видно на карточке).
       Вернуть и скачать их:
         - «Скачать пропущенное» (правый клик) — вернуть то, что было
           отсеяно диапазоном, и сразу скачать;
         - «Докачать весь профиль» (правый клик) — полный список постов,
           качается всё нескачанное, диапазон игнорируется.
    5. Диапазон видно ВСЕГДА и ВЕЗДЕ: на карточке аккаунта, в шапке окна
       «Посты аккаунта» и в файле account.txt внутри папки.
    6. Изменить диапазон в любой момент: правый клик на карточке →
       «Изменить диапазон…» — то же окно с «Все / Последние / Период»,
       с подсказками и проверкой дат. Новое значение применится при
       следующей синхронизации.
    7. Дата «с» не может быть позже даты «по» — программа подскажет.
       Пустой период («Период» без дат) не сохранится — будет ошибка;
       можно оставить только одну границу: пустое «с» = начало профиля,
       пустое «по» = до сегодняшних постов.

РАЗОВОЕ СКАЧИВАНИЕ (БЕЗ БАЗЫ)
  Видео — через yt-dlp. ФОТО-ПОСТЫ (карусели, ссылки вида …/photo/…)
  понимаются тоже: они сразу уходят в gallery-dl (yt-dlp от каруселей
  падает с «код 1» — умеет только музыку). Если yt-dlp не справился
  с любой ссылкой, программа сама пробует gallery-dl. Файлы складываются
  в Downloads/, папку можно открыть кнопкой в сайдбаре.

УПРАВЛЕНИЕ СПИСКОМ
  Кнопки на карточке: Синхронизировать · Папка · Пауза/Пуск · Удалить
  Правый клик — меню: синхронизировать, папка аккаунта, СПИСОК ПОСТОВ,
  копировать ссылку, ИЗМЕНИТЬ ДИАПАЗОН…, заметка, скачать пропущенное,
  ПРОВЕРИТЬ ФАЙЛЫ, докачать весь профиль, пауза, удалить.

  КЛИК ПО КАРТОЧКЕ (по имени, статистике или превью) открывает окно
  «Посты аккаунта» — сетка плиток с ПРЕВЬЮ, как лента в Telegram:
    - обложка поста, под ней дата и статус (скачано / в очереди /
      пропуск / НЕТ ФАЙЛА — красным, если файл удалили из папки);
    - фильтры сверху: Все / Скачанные / Очередь / Пропуск;
    - клик по плитке — подробности: название, ОПИСАНИЕ, путь к файлу;
    - двойной клик — открыть файл системным плеером (нескачанное —
      откроется в браузере на TikTok);
    - правый клик по плитке — меню: открыть, ПЕРЕКАЧАТЬ ПОСТ,
      копировать ссылку / описание / название;
    - превью берутся из media/ (обложки yt-dlp, картинки фото-постов);
      у старых постов без превью программа дотянет обложку через
      официальный oembed TikTok (понемногу, с кэшем на диск) — плитки
      обновятся прямо в открытом окне.

  ПАУЗА (работает по-настоящему):
    - «Пауза» доступна ВСЕГДА — даже когда идёт скачивание (остальные
      кнопки в этот момент гаснут, пауза — нет).
    - Нажатие останавливает работу ПОСЛЕ текущего поста: остаток остаётся
      в очереди и виден на карточке («N в очереди»).
    - На паузе аккаунт пропускается при «Синхронизировать все».
    - «Пуск» снимает паузу и СРАЗУ докачивает остаток очереди.

  СТОП (ОТМЕНА ЗАГРУЗКИ) — красная кнопка рядом с полосой прогресса:
    - появляется только когда идёт скачивание;
    - срабатывает СРАЗУ на любом этапе: раньше во время составления
      списка постов приходилось ждать, пока yt-dlp перечислит весь
      профиль — теперь «Стоп» прерывает и листинг в ту же секунду;
    - отличается от паузы: «Пауза» сохраняет очередь («Пуск» докачает),
      «Стоп» ОЧИЩАЕТ её — остановка после текущего поста, а остальное
      уходит в «вне диапазона»;
    - вернуть очищенное: правый клик → «Скачать пропущенное».

ФОТО-ПОСТЫ (КАРУСЕЛИ)
  Качаются: yt-dlp забирает музыку, gallery-dl — сами картинки.
  В базе они помечены типом «photo».

ОПИСАНИЕ ПОСТОВ
  Описание скачивается вместе с постом и лежит рядом с файлом в media/:
    - видео — текстовый файл «дата_ID.description»;
    - фото-посты — «….json» с полными данными поста.
  Оно же сохраняется в базе и показывается в окне «Посты аккаунта»
  (клик по плитке) — оттуда можно скопировать описание или название
  одной кнопкой/пунктом меню.

ЕСЛИ ФАЙЛЫ УДАЛИЛИ ИЗ ПАПКИ ВРУЧНУЮ
  Программа НЕ перекачивает удалённое сама — вдруг вы удалили
  специально. При каждой синхронизации она только сверяет базу
  с папкой media/:
    - файл на месте — ок;
    - путь в базе сбился, но файл найден по ID поста — путь чинится сам;
    - файла нет — на карточке и в окне постов появится «нет файла»,
      а в журнале — подсказка. Вернуть файл можно ТОЛЬКО вручную:
      - одна плитка: окно постов → ПКМ по плитке → «Перекачать пост»
        (или кнопка «Перекачать» внизу окна);
      - всё пропавшее сразу: правый клик на карточке →
        «Проверить файлы и докачать».

ПЕРЕНОС СТАРОЙ БАЗЫ (от старой однофайловой версии)
  Скопируйте старый tiktok.db в папку программы и запустите. Программа сама:
  перенесёт аккаунты и посты в data/, а файлы из Downloads/<ник> — в
  data/NNNN/media. Старая база сохранится рядом как tiktok.db.bak.
  Папки вида NNNN_ник (от прошлой версии TokSaver) переименуются в NNNN сами.

ЕСЛИ ПРОГРАММА ВООБЩЕ НЕ ЗАПУСТИЛАСЬ
  Появится окно-сообщение «Программа не смогла запуститься» с началом текста
  ошибки, а рядом с «Запустить.bat» — файл crash.log с полным отчётом
  (обычно это недокачанные библиотеки: запустите ещё раз при интернете —
  они доустановятся сами).

ЕСЛИ ПРОГРАММА «МИГНУЛА» И НЕ ОТКРЫЛАСЬ (окно мелькнуло и исчезло)
  Вся диагностика пишется в два файла рядом с «Запустить.bat»:
  - run.log  — полный лог запуска (пишется всегда при запуске без консоли);
  - logs/toksaver.log — подробный технический лог (ошибки, которые не
    показываются в окне; ротируется, не разрастается);
  - crash.log — появляется только при падении, с текстом ошибки.
  Пришлите эти файлы тому, кто сопровождает программу, — в них видна точная
  причина. Также: закройте зависшие копии программы через Диспетчер задач
  (pythonw.exe) и запустите заново.

ЕСЛИ ОШИБКИ / АККАУНТ НЕ СКАЧИВАЕТСЯ
  - «Unable to extract user ID», HTTP 400/503 на embed — программа сама
    пробует несколько путей: страницу профиля, API TikTok, embed-страницу,
    ID по любому посту. Если все не удались, на карточке будет честный
    статус «Ошибка — см. журнал», а в журнале — что делать.
  - «Аккаунт ЗАКРЫТЫЙ (private)» или замок «Log in to TikTok» на открытом
    профиле — нужна авторизация (раздел выше) и подписка на этот аккаунт.
  - Самый надёжный способ добавить проблемный аккаунт — скопировать ссылку
    на ЛЮБОЙ его пост (tiktok.com/@ник/video/…) и добавить её: постоянный
    ID профиля берётся из поста.
  - Все логи — в журнале внизу окна (кнопка «Показать журнал» /
    «Скрыть журнал»; ошибки дублируются всплывающими уведомлениями в углу).

ДЛЯ РАЗРАБОТЧИКА
  Структура: main.py (вход, .venv), paths.py, settings.py, applog.py,
  netutil.py (SOCKS5, докачка, SHA-256, безопасный zip, лимиты), validate.py
  (проверка ввода), thumbs.py (кэш превью), tilegrid.py (раскладка плиток),
  sorting.py (сортировки),
  db.py, engine.py и
  интерфейс по модулям: ui.py (окно, сборка, цикл событий), ui_theme.py,
  ui_widgets.py, ui_calendar.py, ui_edit.py, ui_log.py, ui_cards.py,
  ui_posts.py, ui_actions.py.
  Тесты:   pip install pytest   затем   python -m pytest tests
  Релиз:   python make_release.py  — чистый zip без логов, кэша и ваших данных.
  Один exe через pyinstaller не поддерживается: gallery-dl и pip запускаются
  через интерпретатор Python, которого в exe нет.
  Версии зависимостей: requirements.txt. ByeDPI закреплён в engine.py
  (BYEDPI_VERSION и контрольные суммы).
